Micronaut GraphQL can serve Apollo Federation subgraphs through the standard `GraphQL` bean.
Federation support is added when building the schema, so the existing Micronaut HTTP endpoint continues to handle the federated queries.

To enable federation support, add Apollo's federation support library to your application:

dependency:com.apollographql.federation:federation-graphql-java-support[]

Then transform the schema in your `@Factory` bean before building the `GraphQL` instance:

[source,java]
----
import com.apollographql.federation.graphqljava.Federation;
import graphql.GraphQL;
import graphql.schema.GraphQLSchema;
import graphql.schema.idl.RuntimeWiring;
import graphql.schema.idl.TypeDefinitionRegistry;
import io.micronaut.context.annotation.Bean;
import io.micronaut.context.annotation.Factory;
import jakarta.inject.Singleton;

@Factory
class GraphQLFactory {

    @Bean
    @Singleton
    GraphQL graphQL(TypeDefinitionRegistry typeRegistry, RuntimeWiring runtimeWiring) {
        GraphQLSchema schema = Federation.transform(typeRegistry, runtimeWiring)
            .fetchEntities(env -> {
                // Resolve representations from env.getArgument("representations")
                return List.of();
            })
            .resolveEntityType(env -> env.getSchema().getObjectType("Product"))
            .build();

        return GraphQL.newGraphQL(schema).build();
    }
}
----

When federation is enabled in the schema, Micronaut GraphQL serves the `_service` and `_entities` fields through the same `/graphql` endpoint.
